Typography

Titillium Web for everything structural — titles, subtitles, headings, section labels. Epilogue for everything you actually read — body, quote, caption. Both are free on Google Fonts.

Typography by medium

Different channels use different primary fonts. Pick the right one for your output.

PresentationsInter or Titillium Web depending on contextCalibri
DocumentsTitillium Web (headings) + Epilogue (body)Arial

Common rules across all media

  • Maximum 2 font weights per slide or section — regular + bold. Don't mix three or more.
  • No italic usage in carousels or slides. Reserve italic for pull-quotes in documents only.
  • Short text blocks. 1-2 sentences per paragraph on slides, sentence fragments preferred.
  • Headings are bold and uppercase with wider tracking. On web, set via CSS base layer.

Fallbacks

When the primary font can't load, fall back gracefully. Never substitute with Times.

/* CSS font stacks */
--font-head: "Titillium Web", "Segoe UI", Arial, sans-serif;
--font-body: "Epilogue", "Segoe UI", Arial, sans-serif;
--font-web:  "Inter", system-ui, sans-serif;

Where to get the fonts

  • Epilogue — fonts.google.com/specimen/Epilogue. Free, open-source. Install weights 400 / 500 / 600 / 700.
  • Inter — fonts.google.com/specimen/Inter. Free, open-source. Install weights 400 / 500 / 600 / 700.
