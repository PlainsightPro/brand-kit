06 — Fonts

Typography

One family: Inter. Bold for everything structural (titles, headings, labels, numerals), regular for everything you read. It is free on Google Fonts and it is what plainsight.pro uses. Where Inter is not installed, as in most Office files, Segoe UI or Calibri take its place.

Inter bold: headings

Titles, headings, section labels and numerals, always at 700. Until November 2026 headings were set in Titillium Web; older material in it does not have to be redone, but new work never uses it.

Common rules across all media

  • Maximum 2 font weights per slide or section. In client work: Inter 700 for headings, labels and numerals; Inter 400 for everything you read.
  • No italics anywhere. A quote is set apart by size and colour.
  • Emphasis by colour or a label, never bold body text. Use Plainsight Blue or a small uppercase label.
  • Short text blocks. 1-2 sentences per paragraph on slides, sentence fragments preferred.
  • Section headings, labels and buttons are bold and uppercase with wider tracking. On web, set via CSS base layer.
  • Action titles are sentence case. A title that states the conclusion of a slide or chapter is a full sentence: "Three reports answer the same question", not "REPORTING LANDSCAPE".

Fallbacks

When the primary font can't load, fall back gracefully. Never substitute with Times.

/* CSS font stacks */
--font-head: "Inter", "Segoe UI", Calibri, Arial, sans-serif;
--font-body: "Inter", "Segoe UI", Calibri, Arial, sans-serif;
--font-web:  "Inter", system-ui, sans-serif;

Where to get the fonts

  • Inter: fonts.google.com/specimen/Inter. Free, open-source. Install weights 400 and 700.
  • Segoe UI and Calibri ship with Windows and Microsoft 365. Nothing to install.
