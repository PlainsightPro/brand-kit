Charts & data visualization

Most Plainsight charts use one colour. The moment a chart uses six different colours, it has stopped being a chart and started being a flag.

Chart palette (ordered)

Data is blue. Further series take the blue tints in this order. Orange is not a series colour: it marks the one bar, line or point the title is about.

When to use which

Chart shows…Use colorsExample
One series over time / categories#000075 onlyMonthly revenue, headcount over years
Actual vs. target, before vs. after#000075 for actual, #ADADD4 or a thin blue line for the targetForecast vs. actual. Orange only when the gap is what the title says.
2–4 series, no semantic differenceBlue tints in orderRevenue by region
The one item the title is aboutAll bars #000075 + that one in #d5693a"Gent grew fastest": Gent in orange, the rest blue

Chart rules

  • Title in Inter bold, labels and body in Inter regular. Same hierarchy as everywhere else.
  • Axes in Blue 55%. Gridlines in Blue 18%. The data is the point — axes should recede.
  • The title states the conclusion. "Gent grew fastest in Q3", not "Revenue by office". The orange point is the one that title is about.
  • No 3-D, no pie charts of more than 3 slices, no donut KPIs, no gauges, no rainbows.
  • Sort bar charts by value unless they're time-ordered. Alphabetical bar charts hide the story.
  • Direct-label where you can. A label on the line is better than a legend two inches away. Drop the legend when the labels fit.
  • A source line under every chart, bottom left, in a small uppercase label.
  • Round numbers on axes. Forty-two thousand euros is "€42K", not "€42 137.50".

Power BI theme

Download the JSON file and import it via View → Themes → Browse for themes. Every series starts blue. Orange is the last theme colour: set it by hand on the one bar or line the page title is about. Status colours use words first; the theme maps "bad" to orange so it stands out, never red.

// plainsight-powerbi-theme.json
{
  "name": "Plainsight",
  "dataColors": [
    "#000075", "#3939A0", "#7373AA",
    "#ADADD4", "#d5693a"
  ],
  "background": "#ffffff",
  "foreground": "#000075",
  "tableAccent": "#000075",
  "good": "#000075",
  "neutral": "#7373AA",
  "bad": "#d5693a",
  "maximum": "#000075",
  "center": "#7373AA",
  "minimum": "#ADADD4"
}

matplotlib / Python

Drop this at the top of any notebook to get on-brand charts by default.

import matplotlib as mpl

PS_BLUE   = "#000075"
PS_ORANGE = "#d5693a"
# Blue tints only. Colour the one bar the title is about with PS_ORANGE by hand.
PS_CYCLE  = ["#000075", "#3939A0", "#7373AA", "#ADADD4"]

mpl.rcParams.update({
    "font.family":        "Inter",
    "axes.edgecolor":     PS_BLUE,
    "axes.labelcolor":    PS_BLUE,
    "text.color":         PS_BLUE,
    "axes.titlecolor":    PS_BLUE,
    "axes.prop_cycle":    mpl.cycler(color=PS_CYCLE),
    "figure.facecolor":   "white",
    "axes.facecolor":     "white",
    "axes.spines.top":    False,
    "axes.spines.right":  False,
})
